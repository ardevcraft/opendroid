# OpenDroid Transfer

**Android file transfer for macOS. Built with Rust.**

OpenDroid Transfer is a Rust-based application for transferring files between Android devices and macOS. Created as an alternative to OpenMTP, it focuses on a practical everyday need: moving files between your phone and your Mac.

Whether you are working with photos, videos, documents, or project files, OpenDroid Transfer aims to make Android file transfer a straightforward part of your desktop workflow.

## Purpose

Using an Android device alongside a Mac should feel natural. OpenDroid Transfer is built around that idea, with a focused product direction and an emphasis on clarity, reliability, and ease of use.

The goal is simple: provide a dependable bridge between Android storage and the macOS desktop.

## Project Focus

- **Android and macOS:** Dedicated to file transfers between Android devices and Macs.
- **Rust foundation:** Implemented in Rust, with its emphasis on memory safety and explicit error handling.
- **Focused scope:** Centered on the file-transfer workflow.
- **Everyday usability:** Guided by clear interactions and predictable behavior.

## Engineering Priorities

OpenDroid Transfer's development priorities are reliable transfer behavior, understandable feedback, and maintainable implementation. Device compatibility, connection handling, and useful error reporting are central concerns for the project.

These priorities guide development; supported capabilities and platform requirements should be documented for each release.

## Feedback

When reporting an issue, include your macOS version, Android device model, Android version, application version, and steps to reproduce the problem. Describe the expected result and what happened instead, and remove personal information from any logs or screenshots.
